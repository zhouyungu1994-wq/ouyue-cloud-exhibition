# 水木之间 · 生生瓯越

《城中有声》独立章节动态网页。原有舞台图为核心，完整16:9构图，朱红、墨绿与暖金配色。

## 运行与预览

无需安装依赖。直接打开 index.html，或在此目录运行 `python -m http.server 8768` 后打开 http://localhost:8768 。后者更适合检查媒体和浏览器本地存储。

## 已实现

- 暗场与跟随指针的局部光圈，触屏与键盘也能点击启幕。
- 左右帷幕缓慢拉开，舞台渐亮；随后播放本地音频。
- 开帘、听戏、余音三个状态；支持暂停、拖动进度、静音、跳过、重播和合帘复位。
- 完整透明人物轻微倾身与呼吸、低浓度台口薄雾；暂停音频时动画同步暂停。
- 桌面与手机适配，始终保留完整舞台；尊重系统减少动态效果设置。
- 设置面板：标题、介绍、暗场、光圈、开帘时长、薄雾、音量、动作幅度和来源署名。
- 导入WEBVTT字幕。标注“贫女：”或“张协：”可同步切换人物亮度。
- 本机保存和导出config.js。没有联网写入GitHub的管理员后台。

## 文件

| 文件 | 用途 |
| --- | --- |
| index.html | 页面内容和舞台结构 |
| style.css | 布局、配色、响应式和动画 |
| app.js | 播放状态、开帘、字幕、编辑面板 |
| config.js | 可修改的默认文案、参数和字幕时间点 |
| assets/ | 正式展示所需的舞台、透明图层和音频 |

## 如何编辑

1. 点击“调整画面”，修改参数并即时查看效果。
2. “保存到本机”仅保存到当前浏览器，不改变其他人看到的网页。
3. “导出设置”生成config.js。用导出文件替换本项目的config.js，再提交到GitHub。
4. 全站布局或新功能可通过Codex继续修改源代码。

未导入字幕时不会编造唱词。以下仅为格式说明，不可作为正式字幕：

```text
WEBVTT

00:00.000 --> 00:03.000
贫女：这里填写核实后的唱词
```

字幕导入后也会包含在导出的config.js中。请逐句对照实际录音校正时间。

## 发布准备

这是纯静态网页，可以由GitHub Pages等静态托管服务发布。使用相对资源路径，支持仓库子路径。
现阶段没有自动发布脚本，避免开发提交直接改变公开展览。
请在仓库设置中配置Pages发布来源；若选分支发布，选择main与根目录。网站上线和GitHub仓库保存代码是两个步骤。

## 尚需内容核对

- assets/excerpt.mp3 为本地已有音频，网页会读取其真实时长。
- 演出版本、演员、音频来源和公开使用许可需补全；config.js内可以修改署名。
- 对应唱词尚未核验，默认字幕为空，人物动画只是通用微动，未按具体唱句编排。
- 头部、手臂、水袖尚未单独绑定；本版使用完整人物素材。
- “跳过唱段”抵达本章余音区；其余六个章节未在本项目中构建，未设置虚假的下一章链接。

## 技术边界

不需要在网页中放置GPT API密钥或GitHub令牌。编辑面板只做本地预览与文件导出。
部分浏览器可能要求在开帘完成后再次点击“继续听戏”以允许播放声音；页面会提示。
需要登录、多人在线编辑或一键同步GitHub时，应另做有身份验证的保存服务。
